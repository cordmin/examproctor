개인정보처리방침

시행일: 2026년 11월 6일
시험감독 배정 프로그램(이하 "프로그램")은 사용자의 컴퓨터에서만 동작합니다. 제작자는 프로그램에 입력된 개인정보를 받지 않으며, 별도의 서버에 저장하지도 않습니다.

1. 다루는 정보와 목적
시험감독 배정을 위해 사용자가 직접 입력하거나 파일로 불러온 다음 정보를 다룹니다.
- 교사 이름, 담당 과목, 담임 학급
- 비고(예: 특정 학년 자습감독 불가), 시간별 감독 불가 정보
- 시험 일정, 감독 배정 결과
학생의 개인정보는 입력 대상이 아닙니다. 위 정보는 감독 배정, 결과 확인, 엑셀 파일 작성에만 사용합니다.

2. 저장 위치와 보관 기간
- 작업 내용은 사용자 컴퓨터의 %APPDATA%\시험감독배정 폴더에 자동 저장됩니다.
- 사용자가 저장하거나 내보낸 JSON·엑셀 파일은 사용자가 고른 위치에 저장됩니다.
- 같은 폴더에 창 크기, 화면 설정, 업데이트 설치 기록도 저장됩니다. 설치 기록에는 Windows 사용자 폴더 경로가 포함될 수 있습니다.
- 정보는 사용자가 지울 때까지 컴퓨터에 남습니다.

3. 외부로 나가는 정보
교사 정보와 배정 결과는 외부로 전송되지 않습니다.
프로그램은 새 버전을 확인하고 내려받기 위해 GitHub(github.com)에 접속합니다. 이때 일반 인터넷 접속과 같이 컴퓨터의 IP 주소 등 접속 정보가 GitHub에 전달될 수 있습니다. 이 정보는 제작자에게 전달되지 않으며, GitHub의 개인정보 처리방침을 따릅니다.

4. 제3자 제공과 처리 위탁
제작자는 개인정보를 제3자에게 제공하지 않으며, 개인정보 처리를 위탁하지 않습니다.

5. 정보 파기와 사용자의 권리
- 입력한 정보는 프로그램에서 언제든 수정하거나 지울 수 있습니다.
- 프로그램을 삭제해도 %APPDATA%\시험감독배정 폴더는 남습니다. 정보를 완전히 지우려면 이 폴더와 직접 저장한 파일을 삭제해 주세요.
- 제작자는 사용자의 정보를 갖고 있지 않으므로, 대신 열람하거나 삭제해 드릴 수 없습니다.

6. 안전 관리
저장 파일은 암호화되지 않습니다. 컴퓨터 잠금과 계정 관리, 파일 공유 범위 관리는 사용자와 소속 학교의 관리 기준을 따라 주세요. 다른 사람에게 받은 파일은 믿을 수 있는 경우에만 여세요.
